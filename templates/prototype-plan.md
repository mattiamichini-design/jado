# Prototype plan — design question

## Decision

Which hypothesis will the prototype test, and which choice depends on the result?

## Sources and constraints

Link the brief, evidence, competitor comparison, messaging, UX records and visual contract. Identify the contact for feasibility questions.

## Scope and fidelity

List required paths, states, viewports, content and components. Identify synthetic data, simulated behavior and out-of-scope paths.

## Preparation

1. Reuse documented components and list the alternatives to compare.
2. Implement the interactions required to answer the question; every assigned path must be reachable.
3. Check the path, readability and relevant accessibility; record results and unresolved issues.
4. Prepare the initial state and session task; verify that the session can start from that state.

## Agent assignment

Record the assigned outcome, JADO route and revision, stage, sources, writable files, remaining budget and expected evidence. Preserve repository constraints and concurrent work.

## Observations and next steps

Link the test plan, collected evidence, decision and limits. Identify components to document in Storybook or a PR to agree on; technical integration remains with the team.
