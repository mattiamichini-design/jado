# Project instructions

Adapt this template to the repository's actual work and conventions. Verify every referenced path and command before adopting it.

## Context

Describe the project and point to the sources needed for the requested work.

## Task routing

If the project uses JADO, record its repository path and use `jado-run` for design assignments. `ask-jado` advises on skills, agents, workflows, or next steps and resolves missing decisions during work; `jado-flow` coordinates the selected route and `jado-agent-*` profiles. Advice alone does not start execution. Set the project's dial defaults with a line such as `JADO defaults: stage=explore involvement=autopilot budget=lean`; requests and `jado: …` mid-run override it.

For each task type, link the relevant documents, conventions and tools. When authoring agent-facing instructions, apply `writing-for-agents`; read `SKILL-MECHANICS.md` when writing skills. Write maintained JADO documentation, skills, profile instructions, runtime procedures and templates in English. Product content follows the project's language requirements.

## Execution

Point to the project's run and verification commands. State change conventions, concurrent-work ownership and the source of reusable instructions.

## Verification and delivery

Define required checks by change type, delivery evidence and operations requiring explicit authorization. Adoption is complete when every pointer resolves and every required check has an executable command or a documented manual procedure.
