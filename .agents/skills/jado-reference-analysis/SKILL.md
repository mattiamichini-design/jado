# Reference analysis

## 1. Define the comparison

Record the question, intended deliverable, user task, audience, platform, domain, constraints, and search budget from the brief. Reuse supplied decisions; clarify only missing information that changes selection. Distinguish inspiration, a selected direction, and an approved target.

Build a candidate set of comparable products with a reason for each. Include cross-sector references when their interaction or visual principle transfers to this problem. Familiar brands can guide discovery; search order and brand popularity do not establish quality. Claims about adoption or popularity require a source.

Complete when the comparison criteria and bounded search scope are explicit.

## 2. Inspect relevant sources

For product screens, use `mobbin-search` when available and read its instructions. For flow analysis inspect the actual sequence, decisions, errors, and recovery where accessible; isolated search screenshots do not prove a complete flow. Record missing states as gaps.

For style, branding, or image language, use available browser/image tools for Pinterest, images, and relevant sites. Open the sources and images used, record their URLs, and identify access limits. Tool availability determines what can be inspected; this skill grants no additional access or generation capability.

Size the sweep to the stage: explore favors breadth (roughly 6–10 candidates, a quick look at each); refine favors depth on fewer candidates that bear on the selected direction. Stop when the relevant cases are covered or the assignment budget is reached, and report uncovered cases.

Complete when each candidate used in the comparison has inspected evidence and an observation boundary.

## 3. Select and explain

Compare relevance to the task, clarity, interaction complexity, error handling where observed, and adaptability to the project's constraints. For visual references compare composition, typography, imagery, and tone against the brief. Explain selected and rejected candidates, what to reuse, what to adapt, and what does not transfer. Use a reasoned ranking; numerical scores require an explicit scoring method.

A reference pack records source, observed screen/state, selection rationale, transferable principle, and limits. Produce a moodboard only when assigned. Resolve any saved pack or moodboard location through `jado-evidence-contract` (`.agents/skills/jado-evidence-contract/SKILL.md`); keep one canonical copy and link it in the handoff.

Complete when every recommendation can be traced to an inspected source and project criterion.

## 4. Hand off

The visual researcher delivers annotated references. `jado-art-direction` turns them into a coherent direction when that decision is assigned; the designer applies the selected direction within the assignment. Surface conflicting references before implementation. Research evidence remains distinct from user testing or user approval.
