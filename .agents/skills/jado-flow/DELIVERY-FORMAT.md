# Delivery format

```markdown
## Result
<what was produced, with links to artifacts and captures>

## Checks
| Check | Outcome | Evidence | Coverage |

## Reviews
### UX · ### Visual
<each reviewer's findings as returned, one heading per reviewer>

## Decision log
| Decision | Chosen | Alternatives | Reason | Owner |
<Owner: user, or provisional when taken on the user's behalf>

## Open questions
<numbered, each with the recommended default>

## Next step
<one line>

JADO run · <route> · <stage> · <involvement> · <budget> · delegations <used>/<limit> · fix passes <used> · questions <asked> · <success|partial|blocked|failed>
```

Drop a section that has no content, except the decision log and the run summary line. When project instructions name a JADO run log, append the run summary line there.
