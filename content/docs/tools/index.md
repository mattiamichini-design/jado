| Tool | Purpose | Does not replace |
| --- | --- | --- |
| [UX Planner](/docs/tools/ux-planner) | Personas, journeys, flows and stories in the repository | Research or product decisions |
| [VariantHub](/docs/tools/varianthub) | Compare alternative implementations | The approved component catalog |
| [Storybook](/docs/tools/storybook) | Shared tokens, components, states and interactions | Exploratory comparison |
| [AI coding tools](/docs/tools/codex) | Claude Code, Codex or OpenCode: reconstruct context, write and verify with skills and agents | The canonical source of decisions |
| [Figma](/docs/tools/figma) | A design and handoff surface when chosen by the team | Canonical documents in code |
| GitHub | Version design artifacts and propose contributions through PRs | The lasting explanation of the method |

Tools remain in their own repositories. The playbook preserves why and when to use them, commands verified in sources and responsibility boundaries.
