The installer writes these profiles for Claude Code, Codex and OpenCode: see the [JADO configuration guide](/docs/jado/configuration). Then choose the role for the work at hand.

| Capability | Assignment |
| --- | --- |
| [JADO Agent UX](/docs/automation/agents/jado-agent-ux) | Research, UX architecture, flows, journeys and content in the same context. |
| [JADO Agent Visual](/docs/automation/agents/jado-agent-visual) | References, moodboards, visual direction and canvas in the same context. |
| [JADO Agent Frontend](/docs/automation/agents/jado-agent-frontend) | Design systems, implementation and technical corrections in the same context. |
| [JADO Agent UX Reviewer](/docs/automation/agents/jado-agent-ux-reviewer) | Verifies tasks, comprehension, states and accessibility without modifying the product. |
| [JADO Agent Visual Reviewer](/docs/automation/agents/jado-agent-visual-reviewer) | Compares the result with the selected direction and verifies defects in the final captures. |
