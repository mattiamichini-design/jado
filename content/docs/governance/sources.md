## JADO method

This repository is the method source: JADO's graph, profiles and skills. The [JADO pages](/docs/jado) distinguish generated configuration from runs not yet tested. Upstream skills are fetched from their authors' repositories at install time, and their licenses apply. `jado/skill-inventory.json` records where each one comes from. See [THIRD-PARTY-NOTICES.md](https://github.com/mattiamichini-design/jado/blob/HEAD/THIRD-PARTY-NOTICES.md) in the repository root.

## Skills

The [skill catalog](/docs/automation/skills) contains current design, copy, marketing and research capabilities. Each card links instructions to read: JADO-owned adaptations or the specialist skill's official source. External dependencies keep attribution and provenance in the skill lock and inventory.

The editorial catalog is selective; the inventory also includes internal procedures and native copies. Executing instructions requires the indicated tools and connections: file presence does not install connectors or MCP servers.

## Individual project rules

For code contributions, read `AGENTS.md`, the visual contract and relevant repository instructions. Domain and visual identity choices belong to that project.

The designer's scope covers research, design, code prototypes, user testing, Storybook and contributions through PRs. Detailed research procedures are proposals to adapt, not activities already performed.
