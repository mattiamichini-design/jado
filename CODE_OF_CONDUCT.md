# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in issues, pull requests and discussions is expected to follow it.

Report unacceptable behaviour to the maintainer, [@mattiamichini-design](https://github.com/mattiamichini-design), on GitHub. If the report needs to stay private, use the private reporting form on the repository's Security tab and say that it concerns conduct. Reports are handled in confidence.
